# TTS 万智牌牌表导出工具（中文卡图版）

一个纯前端的网页小工具：把你的万智牌牌表粘贴进来，一键导出 **Tabletop Simulator（桌游模拟器，TTS）** 可直接使用的卡组 JSON 文件。无需安装、无需服务器，打开网页就能用。

## 功能特性

- **中文卡图**：非基础地优先使用「大学院废墟」的中文卡面，更贴近国服玩家习惯。
- **Token 自动导入**：勾选「自动导入指示物」后，工具会自动识别牌表中会生成的指示物（如士兵、精怪、松鼠等），并作为独立卡牌一并导出，在 TTS 里右键即可复制多张。
- **多来源牌表**：支持直接粘贴来自主流牌表网站的文本（格式见下文）。
- **一键导出**：生成 `deck_tts.json`，放进 TTS 的存档目录即可载入。
- **打印卡图**：一键生成 A4、3×3=9 张/页的打印页，按真实 MTG 尺寸排版，浏览器直接打印即可，指示物可选每种打印几张。
- **卡牌预览**：右侧网格每页 3×3 展示卡图，鼠标悬浮任意卡片即可跟随光标放大查看。

## 使用方法

1. 在左侧文本框粘贴牌表内容（见下方格式示例）。
2. 按需勾选选项：
   - **自动修复错误**：解析失败时退化为模糊匹配。
   - **优先中文版本**：尽量使用中文卡图。
   - **自动导入指示物**：自动导出牌组需要的指示物（默认开启）。
3. 点击「导入牌表」，右侧会显示统计与卡牌预览。
4. 点击「导出 TTS JSON」，下载 `deck_tts.json`。
5. 将文件放入 TTS 存档目录：
   - **Windows**：`文档/My Games/Tabletop Simulator/Saves/Saved Objects/`
   - **Mac**：`~/Library/Tabletop Simulator/Saves/Saved Objects`
6. 在 TTS 里「Objects → Saved Objects」即可找到并拖入桌面。

> 想做实体卡代理？点「打印卡图 (A4)」即可生成 3×3 排版的打印页，选 A4 纸、无边距打印后裁切即可。

## 牌表格式

每行 `数量 卡名（系列）编号`，空行和 `//` 开头的注释行会被忽略：

```
1 Sol Ring (CMR) 369
4 Lightning Bolt (MH2) 143
2 Counterspell (M21) 71
3 Thoughtseize (THB) 84
17 Island (ELD) 254
```

编号（ collectors number）和系列可以省略，只写卡名也能识别。

## 支持的牌表网站

以下网站导出的牌表文本均可直接粘贴使用：

- Moxfield
- Archidekt
- MTGGoldfish
- deckstats.net
- TappedOut

## 关于卡图

- 中文卡图来自 **大学院废墟（mtgch.com）**，仅用于桌游模拟器内的非商业娱乐用途。
- 部分卡牌（如基础地、指示物）使用 Scryfall 的英文原图，经代理转发以确保 TTS 内可正常加载。
